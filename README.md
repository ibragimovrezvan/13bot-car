# Telegram Бот для учета зарплаты на автомойке

Бот для учета заработка на автомойке детейлинг. Работает на всех устройствах (телефоны, ПК, веб-версия).

## Возможности

- ➕ **Добавление машин**: Отправляешь фото машины и сумму чека - бот автоматически считает 25%
- 💰 **Зарплата за сегодня**: Одна кнопка показывает сколько заработал сегодня
- 📊 **Зарплата за периоды**: 
  - Период 1-15 число (выплата 20-го числа)
  - Период 16-30 число (выплата 5-го числа следующего месяца)
- 📁 **Экспорт данных**: Скачивание Excel файла с данными о машинах за нужный период

## Как работает бот

1. Когда ты моешь машину, делаешь фото и пишешь сумму чека
2. Бот сохраняет фото и сумму в базу данных
3. Автоматически считает 25% от суммы чека - это твоя зарплата
4. В любой момент можешь посмотреть сколько заработал за сегодня или за период
5. При необходимости можешь скачать Excel файл с данными о всех машинах за период

## Установка

1. **Установи Python 3.8 или выше** (если еще не установлен)
   - Скачай с https://www.python.org/downloads/
   - При установке отметь галочку "Add Python to PATH"

2. **Установи зависимости**:
   Открой командную строку в папке с ботом и выполни:
```bash
pip install -r requirements.txt
```

## Настройка

1. **Создай бота в Telegram**:
   - Открой @BotFather в Telegram
   - Отправь команду `/newbot`
   - Придумай имя бота (например: "МойАвтомойкаBot")
   - Следуй инструкциям и получи токен бота (выглядит как: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

2. **Добавь токен в файл `.env`**:
   Открой файл `.env` и замени `your_bot_token_here` на твой токен:
```
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

## Запуск бота

Запусти бота командой:
```bash
python bot.py
```

Бот будет работать до тех пор, пока ты не остановишь его (Ctrl+C).

## Использование

1. **Запусти бота** командой `python bot.py`
2. **Открой Telegram** на любом устройстве (телефон, ПК, веб)
3. **Найди своего бота** по имени
4. **Начни работу** командой `/start`
5. **Пользуйся кнопками** для добавления машин и просмотра статистики

### Пример использования

1. Нажми "➕ Добавить машину"
2. Отправь фото машины
3. Отправь сумму чека (например: `5000`)
4. Бот покажет: "Сумма чека: 5000 руб., Твоя зарплата (25%): 1250 руб."
5. Повтори для каждой машины

### Периоды выплаты зарплаты

- **20-го числа** выплачивают зарплату за период с 1 по 15 число включительно
- **5-го числа** выплачивают зарплату за период с 16 по 30/31 число включительно

Используй кнопки "Зарплата за период (1-15)" и "Зарплата за период (16-30)" чтобы узнать сколько тебе должны выплатить.

### Экспорт данных

Если нужно показать данные работодателю или сохранить для себя:
1. Нажми "📁 Экспорт данных (1-15)" или "📁 Экспорт данных (16-30)"
2. Бот пришлет Excel файл с таблицей всех машин за период
3. В файле будут: дата, сумма чека, твоя зарплата (25%), описание

## Файлы проекта

- `bot.py` - основной файл бота
- `database.py` - работа с базой данных
- `requirements.txt` - зависимости Python
- `.env` - файл с токеном бота
- `car_wash.db` - база данных (создается автоматически)
- `Procfile` - файл для деплоя на Railway
- `.gitignore` - файл для Git

### Инструкция по деплою на Railway:

1. **Зарегистрируйся на Railway.app**:
   - Перейди на https://railway.app/
   - Нажми "Login" и войди через GitHub или Google
   - Создай аккаунт (бесплатно)

2. **Загрузи код на GitHub**:
   - Создай репозиторий на GitHub
   - Загрузи все файлы из папки проекта в GitHub
   - НЕ загружай файл `.env` (он в .gitignore)

3. **Создай проект на Railway**:
   - На Railway.app нажми "New Project"
   - Выбери "Deploy from GitHub repo"
   - Выбери свой репозиторий с ботом

4. **Добавь переменные окружения**:
   - В проекте Railway перейди в "Variables"
   - Добавь переменную: `TELEGRAM_BOT_TOKEN` = твой токен бота
   - Нажми "Save"

5. **Запусти бота**:
   - Railway автоматически развернет бота
   - Бот будет работать 24/7 бесплатно
   - Лимиты: 500 часов в месяц (хватит для бота)
